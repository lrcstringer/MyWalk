# MyWalk Project Rules

## ABSOLUTE RULE — NO GUESSING, NO LYING

**Never guess, assume, or infer what code does. Always read the actual file before making any claim about it.**

This means:
- Before saying a widget has a certain style, READ its `build()` method.
- Before saying a file has a certain structure, READ the file.
- Before saying "all X are consistent", READ every X — not a sample.
- If an agent or subagent did the research, VERIFY its findings against the actual code before repeating them to the user.
- Never say something is done or correct without having confirmed it in the code.
- Never report a fix as complete without checking the resulting file compiles cleanly.
- If unsure about what a piece of code does, say so — then go read it.

**Violating this rule means telling the user something false. Do not do it.**
